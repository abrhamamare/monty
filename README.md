# Monty Bytecode Interpreter

A C learning project for interpreting Monty stack-based bytecode. The source includes opcode handlers, linked-list utilities, and an interpreter entry point.

## Topics and technologies

C, linked lists, stack/queue operations.

## Getting started

Inspect `main.c` and `monty.h` for supported opcodes and arguments before running. Compile the C sources with GCC on Linux after reviewing dependencies.

## Repository organization

This repository contains educational source code and exercises. Browse the directories and source files for individual implementations; not every exercise is intended to be compiled or run together.

## Technical interview discussion

Inspect opcode dispatch and malformed-input handling; discuss stack underflow, allocation failure, and parser robustness.

## Scope

This is a learning/portfolio repository. It is not presented as a production-ready or independently security-audited application. Features and test coverage vary by exercise.
